# aero
FOR English speakers (if there are any here...)
Epileptics: be careful, there are rapidly changing frames (the appearance of rainbow windows)

This game is for fun and relaxation, so don’t take it seriously.
Play at your own risk — there may be bugs that bite hard (just kidding).
I downloaded the sounds from open sources on the internet,
and the photos too (a couple of photos are of my cat).

 The OST in the background is called Lotus_Waters from the game Yume Nikki.

https://hochykvasik.github.io/aero/

If you like the game, you can leave a review somewhere, and maybe I’ll add some more mini‑games here — but I’m not guaranteeing anything.  Right now I’m planning to take it to version 1.5, and then maybe I’ll add some new games.

Inspiration is taken from the game Progressbar95.
The code is written mainly using DeepSeek.
